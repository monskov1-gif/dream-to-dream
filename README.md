# MR. RUBEN

Подарочная детективная 2D-игра для Рубена от Вари: визуальная новелла, приключение и детектив в одном файле.

**Как запустить:** открыть `index.html` в браузере. Работает на компьютере и на телефоне (лучше в горизонтальной ориентации). Других файлов нет: весь пиксель-арт рисуется в коде, звук генерируется через WebAudio, прогресс сохраняется в браузере.

**Управление**
- ПК: `WASD`/стрелки — ходьба, `Shift` — бег, `E`/`Пробел` — действие, `I` — инвентарь, `Q` — подозреваемые, `J` — расследование, `P` — телефон, `H` — подсказка, `Esc` — пауза.
- Телефон: виртуальный джойстик (коснуться левой половины экрана), кнопка «Действие» справа, кнопки интерфейса вверху.

**Эпизоды:** 1 — Исчезновение, 2 — Тигран, 3 — Тарас, 4 — Марк, 5 — Андрей, 6 — Кирилл, 7 — Саша, 8 — Дима, 9 — Никита, 10 — Гараж.
