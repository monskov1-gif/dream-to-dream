# A Dream of a Dream — A Journey to Dream

Браузерная игра-новелла по концепту 8-серийного сериала «A Dream of a Dream».
Место действия — Нью-Йорк. У персонажей нет имён, только роли (Гордыня, Жадность, …).

Запуск: открыть `index.html` в браузере. Внешних файлов и зависимостей нет.

## Серии
1. Гордыня — старый гитарист, Нижний Ист-Сайд и Вашингтон-сквер
2. Жадность — игрок у казино в Квинсе
3. Похоть — Уильямсбург, Бруклин
4. Зависть — бодега в Бронксе
5. Чревоугодие — переулок в Адской кухне
6. Гнев — хоккеист, ледовая арена в Квинсе
7. Лень — офисная башня в Мидтауне
8. A Dream of a Dream — больница, сон владельца фургона, белая пустота, эпилог

Управление: WASD / стрелки — движение, E / Space — действие, Q — задания, I — инвентарь, Esc — меню.
На телефоне — экранный джойстик и кнопка E.

В консоли браузера `runDreamAudit()` проверяет карты, переходы и отсутствие имён в репликах.
